# Platform Support

Kitsune Agent targets **Kitsune Linux**, an Arch Linux based distribution. It is developed and tested on Linux (Arch, x86_64).

| Platform | Status |
|---|---|
| Linux (Arch, x86_64) | Developed and tested |
| Other Linux distributions | Not tested |
| macOS, Windows, WSL2, Android (Termux) | Code inherited from upstream is present but is not tested or supported by Kitsune Agent |
| Docker, Nix | Not published for Kitsune Agent |

No packaged builds are published for any platform yet. See [Installation](./installation.md).
